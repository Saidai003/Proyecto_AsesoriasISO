# El Problema

La gestión actual de diagnósticos GAP, evidencias y No Conformidades se realiza con herramientas fragmentadas que no aseguran:

- **Trazabilidad normativa**
- **Segregación multi-cliente**
- **Control de estados**

---

# Consecuencias Operacionales

| Problema | Impacto |
|----------|---------|
| Baja trazabilidad | Decisiones repartidas entre planillas, correos y conversaciones |
| Mezcla de información | Riesgo de acceso cruzado entre clientes |
| Seguimiento manual de NC | Difícil conocer el avance real |
| Sin vista centralizada | No hay forma de comparar y validar rápidamente |
| Escalabilidad limitada | Mayor costo operativo por cada cliente nuevo |

---

# ¿Por qué no usar soluciones existentes?

| Alternativa | Limitación principal |
|-------------|---------------------|
| Excel / Drive | Baja trazabilidad, duplicidad, sin segregación |
| ISWO, GOAudits, GRCTools | Complejas, parametrizaciones previas engorrosas, no adaptadas al flujo de la consultora |
| **Plataforma propia** | ✅ Control, simplicidad, adaptabilidad, roadmap propio |
