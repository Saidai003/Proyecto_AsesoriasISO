# Demostración del Sistema

<!-- Esta slide es un marcador para la demo en vivo o video -->

## Flujo a demostrar:

1. Login como Admin → crear workspace y usuarios
2. Login como Responsable → navegar requisitos, cargar evidencia
3. Login como Evaluador → rechazar evidencia, abrir brecha
4. Responsable → aceptar brecha, crear acción correctiva (Kanban)
5. Evaluador → verificar y cerrar brecha
6. Dashboard → visualizar radar de cumplimiento actualizado
